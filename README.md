## 🚀 How to Deploy on GitHub Pages (Step-by-Step)

### Option A: Via GitHub Web Browser (No Installation Needed!)
1. Go to [GitHub.com](https://github.com) and click **New Repository**.
2. Name your repository (e.g., `portfolio` or `<your-username>.github.io`).
3. Set visibility to **Public** and click **Create repository**.
4. In the empty repository screen, click **uploading an existing file**.
5. Drag and drop all the files from this folder (`index.html`, `style.css`, `script.js`, `.github`, etc.) and click **Commit changes**.
6. Go to **Settings** -> **Pages** (on the left menu).
7. Under **Build and deployment**:
   - **Source**: Select `GitHub Actions` (or `Deploy from a branch` -> `main` / `root`).
8. Done! Your portfolio will be live at:
   ```
   https://karthik3315.github.io/
   ```
